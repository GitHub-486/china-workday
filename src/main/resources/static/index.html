管理接口

接口调试台

按左侧菜单选择接口，填写参数后点击调用。
GET

节假日试算

/workday/api/holiday/is-workday
选择一个日期，快速判断是否上班日。
GET

查询某月节假日明细

/workday/api/holiday/month?year=&month=
返回指定年、月的节假日与调休安排。
GET

查询某年全部节假日

/workday/api/holiday/year?year=
返回指定年份所有节假日与调休记录。
KEY

X-API-Token 设置

管理接口需在请求头携带 X-API-Token。在此设置后保存到浏览器本地，调用时自动附带。
POST

手动触发抓取 🔒

/workday/api/admin/crawl
从 gov.cn 官方搜索接口拉取近期年份节假日通知并入库。
GET

导出当年 JSON 🔒

/workday/api/holiday/export?year=
将某年节假日数据导出为 {year}.json，供离线引用。
