# 日期主页设计

## 概述
为 china-workday 新增一个美观的日期主页（独立页面，不替换现有 index.html 调试台）。

## 访问路径
- `/workday/` → `home.html`（新增）
- `/` → `index.html`（保持原有的接口调试台不变）

## 页面布局

### 顶部导航栏
- 左侧：品牌名 "中国假期服务"
- 中间：导航标签页（今日 | 日历 | 查询）
- 右侧：年份切换器（前后箭头 + 年份数字）

### Hero 区（今日概览）
- 大号日期显示（如 "2026年11月2日 星期一"）
- 状态标签：上班 / 休息 / 放假（带颜色标识）
- 距离下个节假日倒计时

### 年度日历网格
- 4列 × 3行，12个月卡片
- 每个日期格子的颜色编码：
  - 法定节假日：红色背景 + 节日名称
  - 调休上班日：橙色背景 + "班" 标记
  - 正常周末：浅灰背景
  - 普通工作日：白色背景
  - 今天：蓝色边框高亮
- 月份标题可点击展开月视图

### 查询区域（折叠面板）
- 日期选择器 + "判断"按钮
- 结果显示：日期、类型、节日名称

### 页脚
- 数据来源说明

## 技术方案
- 纯 HTML + CSS + JS（无框架依赖）
- CSS：独立 `css/style.css`
- JS：独立 `js/app.js`
- 后端：`IndexController` 将 `/workday/` 映射到 `home.html`
- API：复用现有 `/api/holiday/year`, `/api/holiday/is-workday`, `/api/holiday/month`

## 颜色方案
- 法定假日：`#e74c3c` / `#fff5f5`
- 调休上班：`#f39c12` / `#fffaf0`
- 今天高亮：`#3498db`
- 品牌：`#2c3e50`
- 背景：`#f5f7fa`
- 卡片：`#ffffff`

## 组件分解
1. IndexController（后端）- 新建，映射 `/workday/` 到 `home.html`
2. home.html（前端）- 主页面骨架
3. css/style.css - 所有样式
4. js/app.js - 所有交互逻辑
